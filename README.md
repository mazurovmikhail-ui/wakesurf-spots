# Вейксёрф-споты России 🏄

Каталог катерных вейксёрф-спотов России: карта, фильтры, карточки клубов с катерами, ценами, сезоном и контактами.

**Открыть приложение:** https://mazurovmikhail-ui.github.io/wakesurf-spots/

## Что внутри

- 105 спотов в шести макрорегионах: Москва и МО, Санкт-Петербург и ЛО, Северо-Запад, Юг России, Поволжье и Центр, Урал/Сибирь/Дальний Восток
- Интерактивная карта (Leaflet + OpenStreetMap/CARTO)
- Поиск и фильтры: регион, город, обучение, катер, проживание
- В карточке: акватория, катера, волна, цены, сезон, обучение, проживание, контакты, ссылка на Яндекс.Карты
- Прогноз по точке спота: 7 дней погоды и ветра (Open-Meteo), высота волны для морских спотов, «штилевые окна» для стеклянной воды, ссылки на Windguru и Windy

## Данные

Собраны веб-поиском по сайтам и соцсетям клубов в августе 2026 года. Цены и контакты — на момент сбора, год данных указан в карточке. Перед поездкой сверяйтесь с клубом. Кабельные (лебёдочные) парки без катера в базу не включались; смешанные клубы помечены бейджем «+ лебёдка».

Вся база — один файл [`data.js`](data.js): правки и новые споты можно добавлять прямо туда.
