# Дорожная карта: от сайта к мобильному приложению

Ежедневный конвейер улучшений. Каждый день — один пункт: взять первый неотмеченный,
сделать, проверить в браузере, закоммитить, отметить `[x]` с датой. Пункт великоват
для одного дня — сделать часть и дописать рядом, что осталось.

Конечная цель: **полноценное приложение для телефона** (сначала безупречная PWA,
затем Android-пакет через TWA/Bubblewrap; публикация в RuStore — руками владельца).

## Фаза 4б — Монетизация
Ограничение: платёжные аккаунты (Boosty/Patreon/RuStore-платежи) регистрирует владелец;
конвейер готовит анализ, тексты и код, но ничего не публикует от его имени.
- [ ] MONETIZATION.md: анализ моделей и решение «что бесплатно / что платно». Кандидаты:
  (а) подписка Boosty/Patreon с доступом к Pro-функциям (ориентир — whythetrick, $5/мес);
  (б) партнёрка с клубами: платная карточка «клуб+» (фото, бронь, выделение на карте), реферальные записи;
  (в) встроенные покупки в мобильной версии (RuStore, после Фазы 5).
  Базовый принцип: каталог спотов, карта, прогнозы и раздел новичка — всегда бесплатны;
  Pro-кандидаты: безлимит ML-разборов видео в WakeCoach, готовые 3D-модели трюков,
  сравнение с эталоном, офлайн-пакеты, ранний доступ к новым функциям.
- [ ] Реализовать выбранную модель: страница «Pro», мягкие лимиты бесплатного уровня,

## Правила конвейера
- Не ломать работающее: после правки — проверить в браузере (счётчик «N из N спотов», чистая консоль, карта рендерится)
- Тёмная тема — по умолчанию; все новые функции работают на телефоне
- Никаких внешних CDN для критического пути (офлайн PWA); leaflet уже с unpkg — при случае перевести на self-hosted
- Коммит после каждого пункта, отметка `[x] (YYYY-MM-DD)` здесь же
