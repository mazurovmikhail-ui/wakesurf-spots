# Корпус методики Austin Keen (для подсказок приложения)

Второй источник методики — **Austin Keen** (@AustinKeen), чемпион мира по
скимбордингу, ским-стиль вейксёрфинга (часто без финов).
[Канал](https://www.youtube.com/@AustinKeen). Ссылка на ролик: `youtube.com/watch?v=<id>`.

## ⚠️ Статус извлечения
- Субтитры YouTube через API **недоступны** (та же блокировка, что у WakeTime) —
  подробную речь Остина автоматически снять нельзя.
- Описания у Austin Keen в основном **промо/ссылки**, без пошаговых разборов —
  **кроме одного** («180 Shuv»), где выложен полный чек-лист.
- Поэтому корпус = 1 полный разбор + фирменные кью из описаний + каталог how-to роликов.
  Детальную технику остальных нужно снимать из видео (аудио) — нужны тезисы пользователя.

## Стиль и отличие от WakeTime
Austin Keen — **ским-стиль** (лёгкая доска без финов) + скимбординг с берега.
Дополняет WakeTime (та даёт и серф-, и ским-стиль, и лонгборд). Хорош для трюков-вращений.

## 🎯 Полный разбор (есть текстом)

### 180 Shuv it (ским-стиль вейксёрф) — `ggEaeKHIQnY`
Пошагово по методике Austin Keen:
1. **Заезд на топ волны.** На флэте тоже можно, но волна даёт «поп» для вращения — легче.
2. **Флик/скуп.** Задняя нога «выщёлкивает» доску, передняя чуть пинает вперёд.
   **Не переусердствовать** — доску раскрутить нужно совсем немного.
3. **Остаться над доской**, поджать ноги вверх, дать доске докрутиться и «найти» стопы.
4. **Приземление.** После приземления — **вес на заднюю ногу**, чтобы нос не зарылся (nose-dive).

**Ключевой кью (весь трюк):** ведущее плечо смотрит **на катер**, плечи **НЕ вращаются**
(крутится доска под тобой, а не корпус).

---

## 🔑 Фирменные кью Austin Keen (из описаний, переносимы в подсказки)
- **Плечи не вращаются** на шувах/вращениях: ведущее плечо держит направление на катер,
  доска крутится под неподвижным корпусом. → полезно для правила «ось корпуса» в трюках.
- **Вес на заднюю ногу при приземлении** — чтобы не клюнуть носом (nose-dive).
  (Нюанс: на приземлении назад; в спокойной езде WakeTime — вес вперёд. Контекст разный.)
- **Пусть волна даёт «поп»** — заходить на топ волны, а не бороться на флэте.
- **«Не переусердствуй»** — на вращениях доске нужен минимальный импульс.
- Основы для новичка (беседа в ролике-гайде): встать на доску, встать в «карман» волны,
  держать баланс.
