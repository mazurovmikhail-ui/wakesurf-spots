# Откуда взяты пропорции анатомической модели

Профили в `js/anatomy.js` — не на глаз. Они сняты замерами с анатомической модели
реального человека и приведены к росту 1.75 м.

## Эталон

**Visible Human male skin** (`VH_M_Skin.glb`), проект HuBMAP Human Reference Atlas,
лицензия **CC BY 4.0**. Поверхность тела реального мужчины, 92 659 вершин, рост 1.83 м.
Источник: `https://raw.githubusercontent.com/hubmapconsortium/ccf-releases/main/v1.2/models/VH_M_Skin.glb`

Сам файл в репозиторий не кладётся: он нужен был один раз для замеров, в приложении
работает своя процедурная модель (килобайты вместо мегабайтов, гнётся под любую позу).

## Что показали замеры

Для каждого уровня по высоте измерены полуширина (X) и полуглубина (Z), значения
нормированы на рост. Главные выводы, по которым правились профили:

1. **Торс у человека почти круглый в сечении** — глубина составляет 80–90 % ширины.
   Наша модель была плоской (67 %), из-за чего фигура читалась как картонная.
   Сейчас 80 %.
2. **Нога в сечении вытянута спереди-назад**: на голени глубина больше ширины
   (0.045 против 0.037 доли роста), потому что сзади икроножная мышца. Раньше сечения
   были круглыми.
3. **Колено толще, чем казалось** — 0.073 полуширины против наших 0.061.
4. Ширина плеч — 23–25 % роста (мужской канон), подтвердилась.
