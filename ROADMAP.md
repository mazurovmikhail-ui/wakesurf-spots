# Дорожная карта: от сайта к мобильному приложению

Ежедневный конвейер улучшений. Каждый день — один пункт: взять первый неотмеченный,
сделать, проверить в браузере, закоммитить, отметить `[x]` с датой. Пункт великоват
для одного дня — сделать часть и дописать рядом, что осталось.

Конечная цель: **полноценное приложение для телефона** (сначала безупречная PWA,
затем Android-пакет через TWA/Bubblewrap; публикация в RuStore — руками владельца).

## Правила конвейера
- Не ломать работающее: после правки — проверить в браузере (счётчик «N из N спотов», чистая консоль, карта рендерится)
- Тёмная тема — по умолчанию; все новые функции работают на телефоне
- Никаких внешних CDN для критического пути (офлайн PWA); leaflet уже с unpkg — при случае перевести на self-hosted
- Коммит после каждого пункта, отметка `[x] (YYYY-MM-DD)` здесь же
