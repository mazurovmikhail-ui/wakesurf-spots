# Анализ аналогов (август 2026)

Короткий вывод: точного аналога у приложения нет. Есть соседи по нише, каждый закрывает свою часть — полной картины катерного вейксёрфинга России не даёт ни один.

## Существующие ресурсы

### Россия

| Ресурс | Что это | Отличие от нашего каталога |
|---|---|---|

### Мир

- **WakeScout** — 2000+ точек в 91 стране, но это общий справочник всего водного (клубы, школы, марины, канатки), заметно устаревший (расцвет ~2014), Россия покрыта слабо.
- **WakeSurfSpots.com** — справочник озёр США, где вейксёрф разрешён, с правилами водоёмов. Только США.
- **Wakespot** — приложение про кабельные парки мира (200+).
- **Wake App** — трекер трюков со списком спотов.

## Чего нет у конкурентов (и есть здесь)

1. **Полнота по катерному вейксёрфу РФ** — 105 спотов от Калининграда до Владивостока, включая клубы вне всех каталогов (Сургут, Ижевск, Барнаул, Тульская область).
2. **Прогноз под вейкера** — штилевые окна для стеклянной воды, высота волны и температура моря по точке спота.
3. **Сравнимые цены** — нормализованные ₽/мин с сортировкой.
4. **Катера моделями** — какой буксировщик даёт волну.
5. **Проживание** — фильтр «где остаться на выходные».
6. **Открытые данные** — база одним файлом на GitHub, любой может поправить.

## Где конкуренты сильнее

- **Онлайн-запись** (prowakesurf, naspote, yclients-виджеты клубов) — у нас только контакты.
- **Отзывы** (2ГИС, Яндекс.Карты) — у нас их нет, статике негде хранить.
- **Самообновление** — у живых сервисов данные правят сами клубы; наша база собрана разово и стареет без ручных обновлений. Для контроля свежести в карточках выводится дата проверки данных.
